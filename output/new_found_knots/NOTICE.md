# Machine-knot curves of the class S_24_d961_D6_amphi — licence

The three `.fseries` files below this folder (`kf191`, `kf201`, `kf202`) are Fourier centrelines produced by the knot family machine
of this repository (`machines/the_knotfamily_machine/`). They are shipped because the identity check
`machines/trainstation_sundown_isometry_20260917/nitro_isometry.py` compares the sculpture Nitro with them.

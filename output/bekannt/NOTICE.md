# Machine-knot curves of known table knots — licence

The 222 `.fseries` files below this folder are Fourier centrelines produced by the knot machines of this repository and identified
with knots from the standard tables (folder name `<table name>__<machine name>`). They are shipped because several machines read them
as input (`machines/47_breeding_for_strangeness`, `machines/49_bending_space_conformally`; `machines/111_reversing_the_arrow` reads
the demo outputs of machines 47, 84 and 80).
